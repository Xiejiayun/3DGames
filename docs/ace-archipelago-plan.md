# Ace Archipelago · 王牌群岛 — 3D 现代海岛空战设计与实施方案

> 本方案严格遵循「**单 HTML 文件全内置**」原则：所有 3D 程序化模型、GLSL 着色器、飞行物理、AI 战术、HUD/座舱 UI、Web Audio 合成音效与中英双语系统均内置于 [`games/ace.html`](../games/ace.html) 单文件中，零外部模型/音频/贴图依赖，加载快且支持直接部署到 Cloudflare Workers。

## 3. 三关递进式海岛战役

```mermaid
flowchart LR
    M1["第 1 关：晴空群岛拦截<br/>晴朗正午 · 碧海白沙"] --> M2["第 2 关：黄昏峡湾突袭<br/>落日余晖 · 火山峡谷"]
    M2 --> M3["第 3 关：雷暴航母决战<br/>闪电雷暴 · 怒海狂涛"]
```

### 第 1 关：晴空群岛拦截（Clear Archipelago Intercept）
- **视觉氛围**：正午湛蓝晴空、翠绿火山群岛与白色沙滩、柔和层积云海、清澈反光海面与友军海岛空军基地。
- **核心目标**：拦截 2 波敌方截击机编队与逼近基地的 3 架重型轰炸机编队。

### 第 2 关：黄昏峡湾突袭（Sunset Fjord Radar Strike）
- **视觉氛围**：金红色黄昏逆光、长投影火山岩壁、可高速穿飞的**巨型天然海蚀石拱门**、海面金色波光。
- **核心目标**：摧毁分布在高地与海岸的 **4 座远程预警雷达站**、**2 座防空导弹阵地（SAM）** 与升空拦截中队。

### 第 3 关：雷暴航母决战（Stormy Carrier Fleet Showdown）
- **视觉氛围**：阴沉雷暴云层、周期性 3D 分叉闪电照亮云海与海面、暗青色大浪海面、防空曳光弹划破夜空。
- **核心目标**：击沉 2 艘护航宙斯盾驱逐舰、摧毁 300 米级敌方航空母舰，并与升空的王牌长机 **「Crimson-1 · 绯红一号」** 决战。

## 4. 飞行物理与操控方案

**第一次出击：**机库默认勾选「辅助发射」。朝选中的方框飞，按住空格、右键或触屏「发射」，游戏会在锁定时发出一次；尚未锁定就松手，不扣弹。HUD 将「已发射」和实际碰撞后的「已命中」分开显示。松手再按才会请求下一次发射；暂停、换装或手动换目标会取消等待。在机库或暂停菜单取消勾选即可恢复经典即时发射。

| 操作 | 键位 | 效果说明 |
| --- | --- | --- |
| **指向转向** | `鼠标移动` | 战机自动以优雅的滚转压坡 + 俯仰追踪屏幕准星方向（支持灵敏度与 Y 轴反转设置） |
| **油门 / 加力** | `W`（加力）/ `S`（减速气刹） | 常规巡航 → 加力冲刺（FOV 拉宽 + 尾焰拉长）/ 减速急转咬尾 |
| **手动滚转** | `A` / `D` | 辅助压坡翻滚、低空贴海拉升、躲避弹道 |
| **机炮扫射** | `鼠标左键` | 高射速曳光机炮，配合屏幕上的**动态提前量预瞄圈**精准扫射 |
| **发射导弹** | `鼠标右键` 或 `Space` | 发射当前选定导弹（标准空空弹 MSL / 专属特武 SPW） |
| **切换武器** | `Q` 或 `Tab` | 在标准制导导弹（MSL）与机型专属特武（SPW）间切换 |
| **切换锁定目标** | `E` | 切换主目标 |
| **释放热诱弹** | `F` 或 `Shift` | 抛出耀眼热焰弹簇，甩开正在追踪的敌方导弹 |
| **切换视角** | `V` 或 `C` | 第三人称电影追尾视角 ↔ 第一人称 3D 座舱视角无缝切换 |
| **暂停 / 菜单** | `Esc` 或 `P` | 暂停游戏、调节画质/音效/灵敏度/语言 |

## 5. 大制作级 3D 场景构建、GLSL 着色器与音效架构

### 5.1 电影级渲染管线与光影系统
- **ACES Filmic 色调映射 + 程序化 IBL 环境反射**：通过 `PMREMGenerator` 实时烘焙每一关的天空穹顶为环境反射贴图，让隐身战机蒙皮、透明座舱盖和航母甲板真实反射晴空、夕阳或雷暴光影。
- **HDR 辉光后期（UnrealBloomPass）**：为加力燃烧室、马赫环、太阳海面反光、曳光弹、导弹尾焰、雷达警示灯与爆炸火球赋予电影级辉光。
- **大气透视与海拔雾（Aerial Perspective + FogExp2）**：天空、海面、火山地形及 3D 地标统一接入距离衰减大气散射，彻底消除网页 3D 的塑料感。
- **画质三档切换（High / Med / Low）**：支持动态调整像素比、阴影、云层密度与 Bloom。

### 5.2 动态海面着色器（AAA Ocean Shader）
- 6 层方向 Gerstner 波浪 + 程序化 FBM 微观法线涟漪。
- 物理菲涅尔反射 + 太阳高光路径（Sun Glint）。
- 传入岛屿半径生成**浅滩青色水色过渡与动态拍岸白浪泡沫（Shoreline Foam）**。
- 传入舰船航向生成**开尔文航行白沫尾迹（Kelvin Wake）**，战机贴海掠过激起水雾。

### 5.3 海岛地貌、立体云海与舰队战机
- **坡度 + 海拔混合材质着色器**：自动按法线斜率与海拔混合湿沙、白沙滩、热带植被与陡峭层理玄武岩壁。
- **受光立体云海**：双色受光积云团（向阳面暖亮、背光底面偏暗、边缘银边透射）。
- **300 米级航母与驱逐舰**：斜角飞行甲板标线、旋转雷达舰岛、防空曳光弹与 SAM 发射。
- **精雕可动战机**：随操控实时偏转的副翼舵面、半透明座舱盖、双喷口加力尾焰 + 马赫环 + 高过载翼尖涡流，以及独立 3D 第一人称座舱框架与发光 MFD 仪表。

### 5.4 程序化 Web Audio 合成引擎
- 连续涡扇发动机低频轰鸣（随油门实时调频）+ 加力燃烧室喷射白噪、机炮连射脉冲、导弹点火呼啸、红外锁定蜂鸣、来袭导弹警报、爆炸低频冲击波与第 3 关闷雷。

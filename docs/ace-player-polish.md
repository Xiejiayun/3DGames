# 王牌群岛：从第一次出击到画面验收

## 一次不看说明书的首飞

基线：`830a80d`，默认第一关 / F-22X / 高画质，1100×660，Chromium WebGL。操作是点「立即出击」、按空格、按 V、按 P；没有改目标位置、生命、弹药或任务计时。在机库能看出三架飞机的外形，游戏也有自动选目标和命中判定。问题在于**玩家不知道现在哪一个操作有用**。

- 出击后看到的是四个方框、中央两个重叠的准星和「空格 发射」。一次采样中，按键时选中目标约 2,121 米，锁定进度 0，弹量从 2 变 1，新发射物没有跟踪目标。它仍可能碰巧撞上别的目标；看见烟尾并不能说明锁定成功。要求新玩家读懂颜色和旋转菱形，不如直接告诉他该做什么。
- 鼠标从屏幕中央略微偏移就会持续转向；追尾相机的屏幕中心与飞机前进方向的投影也不是同一点。转身后，屏幕边缘只有箭头。应先让玩家能稳稳地回正、找回目标，再要求他同时瞄准、选武器和躲避。
- 座舱里能看清地平线，但挡风框像一根圆管，遮光罩是一大片同色斜面，三个显示区画在同一片板上。优先做驾驶员眼前的厚度、遮挡和可读性，而不是增加看不见的座椅底部多边形。
- 现有回归以摆位目标覆盖三关结算；这验证了规则，不代表新手自然通关。软件渲染也不代表真机帧率。两者都不能作为「已达到 AAA」的证据。

## 任务表

任务按玩家受益排序；每行一个可独立回退的 PR。每次先 fetch 最新 `origin/main`，验证改动范围、实际输入、截图及适用的回归，再合并。状态以 PR 的合并记录为准。

| 编号 | 任务（对象） | 可复验的交付标准 |
| --- | --- | --- |
| A1 · P0 | 第一次命中：默认辅助发射，保留经典操作 | 默认首关从机库出发，不摆靶、不改血；能区分接近、对准、锁定、可发射和实际命中。早按不白耗弹，松手或暂停不会偷偷补发。键鼠与真实触控事件均验收，中英文不靠颜色猜。 |
| A2 · P0 | 第一人称座舱：遮光罩、独立仪表舱、玻璃托架和舱框 | 在三架飞机实际眼点对比日间、逆光、低画质：能看出凹凸、屏幕嵌入面板、前后层次；准星和地平线无遮挡，三块显示区仍可见。保持现有座舱 ≤5 次颜色通道绘制。 |
| A3 · P0 | 容易回正的转向：中位死区、细调曲线、主动改平 | 鼠标微抖不带偏；触屏松手和方向键松开不留输入；明确的操作可从倾斜姿态恢复，不抢玩家主动翻滚。经典操控保留原始响应。 |
| A4 · P1 | 追尾视角准星与命中反馈 | 在不同纵横比、相机倾斜及油门下，提示位置与实际游戏射线投影一致；低帧步长下穿过目标也应产生一次且仅一次命中。 |
| A5 · P1 | 玩家机体与敌机：进气道、框式舱盖、喷口、近远轮廓 | 三架机以相同机位检视；机库近景看到结构，追尾画面不闪烁，远处靠轮廓而不是小字区别普通机与大型机。外形不能改变碰撞尺寸。 |
| A6 · P1 | [海岛与机场：崖壁断面、滩线、跑道和机库门洞](ace-coasts-airfield.md) | 用起飞相机和贴海相机对照；岸线给出高度参照，崖岩不再是一整片光滑渐变；跑道/建筑落地，新增细节远处不闪烁。 |
| A7 · P1 | 海上舰船与峡湾地标：分层甲板、舰岛、海蚀拱门 | 在任务实际接近距离能凭轮廓区分地标；近距看得到甲板与舰体厚度，拱门可穿过；新增细节不改变巡航和水线。 |
| A8 · P1 | 帧时间与资源回收（持续飞行、暂停和重进） | 同设备、同机位、同质量比较热身后帧时间中位数/P95，单列爆炸和雷暴；记录调用数与三次重开的资源计数。暂停时不白白提交静止画面，恢复不跳步。 |
| A9 · 验收 | 新玩家与真机抽测 | 找至少 3 位未读攻略的玩家，记录从出击到首次命中的时间、重试次数和误解点；目标为 3 人中至少 2 人在 60 秒内首次命中。再测一台集显电脑和一部手机；保留设备、分辨率、画质、复现步骤及已知限制。未测不打勾。 |

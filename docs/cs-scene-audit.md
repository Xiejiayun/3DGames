# CS 3D 场景审查与验收

审查基线：`8b03275`（2026-11-17 的 `origin/main`）。五个任务与无尽模式共用港口地图，不是五张不同的地图。范围包含地图所有分区、人物、道具/特效、第一人称场景和商店场景；不涉及其他两个游戏。

| 分组 | 问题与复现 | 验收 |
| --- | --- | --- |
| 仓库、屋顶、坡道 | 地面无法导航到屋顶，65 个导航点中有 8 个与地面不连通；节点 57/58 嵌入斜坡。栏杆和沙袋只有网格，身体/子弹能穿过。 | 所有节点净空且连通；往返坡道可走；沙袋挡弹、栏杆实体部分有碰撞，栏杆空隙可射击。 |
| 集装箱货场、油桶、地图渲染 | 阴影仅初始化一次，油桶爆炸后留下完整桶影；WebGL context 恢复没有重新标记静态阴影。 | 爆炸、任务重置、context 恢复后重建阴影；保留地图、任务和输入状态的正确边界。 |
| 北侧卡车、中路叉车、南侧堆高机 | 叉车碰撞高度 2.1 m 而顶棚达到 2.655 m；堆高机碰撞高 2.6 m，驾驶室到 3.35 m，吊臂/吊具无碰撞；驾驶室玻璃被实心外壳包裹。 | 模型外形与碰撞匹配；玻璃可见；保留主要通路；车辆补齐必要结构细节。 |
| 岸边、水面、吊机、货船、天空 | 高画质水面过强地反射摄影棚环境光，呈大片奶油色斑块；船舷和吊机驾驶室细节不足。 | 高/中/低画质水面可辨识，保留波纹；增加能从岸上看清的船舷与驾驶室细节。 |
| 第一人称武器、手部、弹壳 | 固定垂直 FOV 在窄窗口裁掉武器；失焦只释放按键，fallback 控制模式下仍继续战斗。 | 窄窗口能看见武器；枪口曳光与屏幕投影一致；失焦暂停、恢复无残留按键。 |
| 商店预览、阵营缩略图 | 使用固定手填尺寸取景，旋转时手枪可越过画面；切换画质只更新主渲染器。 | 所有 7 个预览模型及缩略图留有边距；旋转不裁切；画质与 context 恢复一致。 |

## 验证方式

- `node --test scripts/test-cs.mjs`：直接载入 HTML 中的实际物理/导航代码，回归坡道、障碍、净空和步进碰撞。
- 浏览器使用真实 Three.js/WebGL：截图检查仓库、货场、屋顶、北侧车辆、南侧车辆、货船/吊机；检查 65 个节点与所有守卫出生点；CT/T 两阵营、全部武器、五个任务与无尽模式、商店、暂停/恢复、窗口调整和 context 丢失/恢复。
- 每个 PR 运行静态站点构建及部署 dry-run，等待 PR CI 成功再合并。生产发布由现有 main 工作流负责，合并与部署结果分别记录。

本清单记录本轮代码与浏览器审查可复现的问题；美术精细度仍可继续迭代，不能用有限视角证明任何视角都绝无瑕疵。

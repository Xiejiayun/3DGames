## 验证方式

- `node --test scripts/test-cs.mjs`：直接载入 HTML 中的实际物理/导航代码，回归坡道、障碍、净空和步进碰撞。
- 浏览器使用真实 Three.js/WebGL：截图检查仓库、货场、屋顶、北侧车辆、南侧车辆、货船/吊机；检查 65 个节点与所有守卫出生点；CT/T 两阵营、全部武器、五个任务与无尽模式、商店、暂停/恢复、窗口调整和 context 丢失/恢复。
- 每个 PR 运行静态站点构建及部署 dry-run，等待 PR CI 成功再合并。生产发布由现有 main 工作流负责，合并与部署结果分别记录。

本清单记录本轮代码与浏览器审查可复现的问题；美术精细度仍可继续迭代，不能用有限视角证明任何视角都绝无瑕疵。

## 本轮结果

六组问题均已修复。仓库 #16、货场 #17、车辆 #18、港口 #19、第一人称 #21 均已通过 CI 合并；商店取景及综合回归随最后一组交付。

- CT/T 两阵营 × 任务 1–5 与无尽首关，全部敌人出生点没有嵌入几何；六种持有物切换渲染；开枪、换弹及狙击开/关镜回归。
- 7 个预览模型 × 3 种裁切比例 × 24 个旋转角度，实际顶点投影均在画框内；缩略图拍摄保留当前模型和旋转进度。
- 高/中/低画质同步、480×900 窄窗口、枪口投影、失焦暂停、主场景与商店各自的 WebGL 丢失/恢复均已验证。
- `npm test` 包含 6 项物理/导航、阴影、武器 FOV 和预览取景回归；浏览器检查结束无 pageerror。

### 重跑浏览器检查

执行 `npm ci`、`npx playwright install chromium`，然后 `npm run test:cs:browser`。默认截图和 JSON 报告写入已忽略的 `.cs-qa/`；PR CI 同样运行该检查，并保存截图和报告 7 天。

已安装 Chrome 时可用 `CS_CHROME` 指定可执行文件；`CS_QA_OUTPUT` 指定截图和报告目录；`PLAYWRIGHT_MODULE` 可复用外部已安装的 Playwright 包。浏览器测试仍从页面真实的 Three.js CDN 加载，不替换引擎。

# 卡丁车 3D 审查与验收

基线：`8b03275`（2026-11-17 的远程 main）。范围为 `games/kart.html` 的全部三个赛道、三个赛车/车手和六类道具效果。保持程序化建模、现有操控和单页发布方式。以下列出已确认的问题；审美精细程度仍需人工画面复查，不能用自动测试证明“没有任何问题”。

| 分组 | 问题与复现位置 | 验收目标 |
| --- | --- | --- |
| 公共赛道 | 远景/侧视道路是没有厚度、没有支撑的悬浮薄片 | 连续侧壁、底面和落地桥墩 |
| 公共赛道 | 加速带法线朝下；跳台是倾斜方块，触发球超出实体宽度 | 加速带朝上；楔形坡面；仅经过坡面才能起跳 |
| 公共资源 | 切换赛道只销毁材质，不销毁道路生成纹理；预览/赛车/投射物被移除后 GPU 资源仍保留 | 切换、重开、返回菜单后资源回收，公用轮胎纹理保留 |
| 海滨 | 海面高度 -0.6，低洼道路约 -2.5，海面直接穿过路面；地面也离树根有距离 | 海面避让通行区域，海底/陆地有明确高度关系 |
| 海滨 | 隧道玻璃使用旋转半圆柱，轴线/半圆方向和拱肋不匹配，段间有缺口 | 沿赛道采样生成连续拱壳，通行净空充分 |
| 海滨 | 斜拉索按固定角度摆放，端点没有接到桥塔与桥面 | 拉索端点明确连接，塔基受支撑 |
| 海滨 | 说明中的鱼群、海鸥完全缺失 | 可辨认的鱼身/尾鳍、鸟身/双翼，在路外活动 |
| 海滨 | 灯塔仅三件几何体，热气球吊篮悬空；棕榈叶聚成锥束，树根浮空 | 灯室/顶盖/基座，吊绳，展开叶片与落地树根 |
| 森林 | 瀑布是静止单面矩形，崖体为方块；说明中的木吊桥、潭水、洞穴缺失 | 分层崖壁、流水/泡沫、潭水、实体桥面/悬索，连续洞顶 |
| 森林 | “巨杉”实为小锥形松树，树根离地 2.2 单位，缺少岩石 | 有树皮/根部/分层树冠的高大树木，落地岩石，避开赛道 |
| 森林 | 水晶柱是孤立门框，无洞穴体积，水晶位置挤入路肩 | 连续洞穴围护、分簇水晶位于护栏外 |
| 雪山 | 冰晶隧道只有孤立半圆环，无晶簇和围护 | 连续冰顶、可辨认的晶簇、足够净空 |
| 雪山 | 三辆缆车只是红方块与短杆，在空中正弦往返，没有缆线、塔架和车窗 | 吊架接缆线，沿同一条闭合缆路匀速运行，塔架落地 |
| 雪山 | 说明中的冰湖缺失，松树悬空；雪花跌到固定 y=0 就重置 | 独立冰湖与岸边，树根落地，雪落到实际地面 |
| 赛车/车手 | 坡道只倾斜车身，四轮不跟随；特技时轮子留在原位；前轮半径低于路面 | 整车随坡度/特技一起旋转，轮胎接触路面 |
| 赛车/车手 | 封闭实心轮毂遮住轮辐和刹车；V8 防滚架缺横梁、涡扇罩内面不可见 | 开放轮圈/轮辐、完整防滚架和双面风道 |
| 赛车/车手 | 头饰包住正脸、手套没有握住方向盘、双马尾/围巾分段不连贯 | 正脸可见，手套接方向盘，配饰根部连续 |
| 道具 | 香蕉只是黄锥体；导弹弹头朝后，无尾翼和喷口；香蕉不会贴合坡道 | 三瓣香蕉皮、朝前弹头/尾翼/喷口，落地道具贴路 |
| 摄像机/预览 | 驾驶舱相机位于角色头内，预览固定比例造成窄屏变形 | 驾驶舱避开头部，预览按实际容器尺寸更新 |

修复按公共基础、海滨、森林、雪山、赛车与道具分别提交 PR，均以 main 为目标。每组从当时最新 main 新建独立 worktree 和分支，避免把无关修改带入同一 PR。

## 本地验证

```sh
npm ci
npx playwright install chromium
npm run test:kart
npm run build
npx cf deploy --prebuilt --mode production --dry-run
```

浏览器检查仅在响应内注入诊断接口，发布 HTML 不暴露调试 API。检查三个赛道的几何有效性、道路法线、支撑结构、起跳模型、赛车/道具、切换资源，以及桌面与手机画面。截图输出到系统临时目录，可通过 `KART_SCREENSHOTS` 指定位置。最终仍需查看截图并检查比赛操控与视觉遮挡。HQ/LQ 的截图用于功能检查，不据此宣称性能改善。

## 发布与恢复

main 合并触发仓库既有 Cloudflare 工作流。PR 先通过相同 build/dry-run，再合并；检查主分支工作流成功及线上入口、赛道切换和开始比赛。若出现严重回归，按 README 在 Cloudflare Deployments 回到上一版本，并在 Git 中 revert 对应 PR，避免下次部署覆盖恢复版本。不涉及数据库变更。
